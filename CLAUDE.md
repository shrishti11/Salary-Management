# CLAUDE.md

## Project Overview
We are building an **Employee Compensation Management and Analytics System** to help HR teams manage employee records, salary information, compensation history, and analytics in one centralized application.

Refer to the documents in `docs/` for the product requirements, tech stack, architecture, modules, and use cases.

## Development Guidelines
- Read the relevant documentation and inspect the existing code before making changes.
- Follow the defined architecture, tech stack, and existing project conventions.
- Build incrementally, focusing on one module or feature at a time.
- Prefer simple, readable, maintainable solutions over unnecessary complexity.
- Write meaningful tests and run relevant checks before considering work complete.
- Do not introduce new dependencies or expand the product scope without a clear reason.

## Module Completion
After completing each module or significant feature:

- Verify the implementation and run relevant tests.
- Update the relevant documentation to reflect what was actually built.
- Create a short implementation summary in `docs/implementation/`, covering key changes, decisions, APIs, database changes, tests, and any known limitations.
- Summarize the original task/prompt, what was completed, and what should be done next, so a future Claude Code session can continue without losing context.
- Update the overall module status in the project documentation, where applicable.

## Working Approach
Before starting a significant task, briefly explain the proposed plan and wait for approval. After implementation, report what changed, tests performed, documentation updated, and any remaining work.

Do not implement the entire application at once. Prioritize correctness, data integrity, usability, and maintainability.
